# v0.2.3 整理计划

六项范围已由用户确认。归档历史成果，保留当前版本与 v0.2.2 回滚依据，保持真实业务数据完整。

## 执行顺序与验收
1. 保存完整 Git bundle、未提交补丁及新增文件；bundle verify 通过。
2. 核查运行挂载，归档生成目录；原位置与恢复位置可查。
3. 导出停止测试容器证据，按具体名单移除容器；正式容器身份不变。
4. 未占用且已合并的本地分支归档后清理；未合并及脏工作区单独处理。
5. 盘点源码注释，分批补充核心边界说明；文档改动不得改变业务语法结构。
6. 建立维护指南，验证受影响文件及服务健康。
7. 核对 v0.2.2 与现有配置/数据的兼容性后，才精简其余回滚镜像。
8. 在用状态目录迁移先准备副本、校验和恢复步骤，允许短暂停机后执行。

## 保护范围
不自动推送、不移动历史标签，不删除原件、模型或正式数据卷。归档中的私密配置仅本机保管。
