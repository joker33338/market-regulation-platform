# 客户端、任务和上传页面

实现提交：`4767e71`。客户端为可注入 httpx 异步 transport。
默认 Mock 必须有 MockTransport，不能意外访问外部。远程模式必须显式配置服务。
本地解析仍可由 local 模式选择，需已有对应本地解析依赖。

任务请求键按用户唯一，并与文件名、SHA-256、模式、Provider、服务地址、模型及输出配置绑定。
同键同内容复用，不同内容返回 409；队列计数和新增在 SQLite 单个事务内完成。
创建前记录 submission_started，响应未知不重新 POST；已有远程 ID 在重启后先 GET。
PUT 中断后查询状态；成功 PUT 记录不会重复传输。下载过期后查询新链接，有限重试。
远程完成不等于本地完成；结果及配置的 PostgreSQL 写入成功后才公布本地完成。

API 仅使用一个 ASGI 进程，固定数量 worker 和有限轮询，不使用无界后台线程。
TaskRepository 不是分布式队列，不支持多进程或多主机共享任务文件。
自部署 MinerU 自身可能在服务重启后丢失任务；404 不会触发客户端重新创建。

本地页面 GET / 不含凭据；以下 API 均要求工作台 Bearer 访问码并按 owner 隔离：

| 方法与路径 | 用途 |
| --- | --- |
| POST /api/parse/files?file_name=... | 原始字节上传，大小/后缀/签名验证 |
| POST /api/parse/tasks | JSON file_ids；Idempotency-Key 必填 |
| GET /api/parse/tasks/{id} | 状态和 database_parse_id |
| GET /api/parse/tasks/{id}/results | 已完成的标准化结果 |
| GET /api/parse/tasks/{id}/errors | 脱敏错误码 |
| POST /api/parse/tasks/{id}/resume | 恢复查询或结果入库失败 |
| POST /api/parse/tasks/{id}/cancel | 自部署远程取消；官网仅本地取消 |
| GET /api/parse/tasks/{id}/files/{file_id}/artifact | 授权下载原始产物 |

页面在当前选择中保留请求键及已上传 ID，重试不重新创建任务。切换文件或访问码开始新选择。
原始产物与远程正文保留，表格不摊平成法条。Mock 产物不能进入法律知识库。
