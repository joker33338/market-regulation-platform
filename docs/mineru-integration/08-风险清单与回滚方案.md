# 风险与回退

- 当前为本机单进程可用版本；SQLite 任务库不适用于多实例部署，任务记录和原始文件需一起备份。
- 官网与自部署是不同协议，vlm 不等于 Standard。官网取消只有本地停止，不能声称远程作业已终止。
- 官网 Key、数据库密码、签名链接、原始资料与本地运行配置不得提交或发送给其他主机。
- 来源白名单是精确 origin；未来官网更换下载域名时需要审查后配置，不能直接放开任意 URL。
- ZIP 受压缩包大小、展开总量、成员数量及路径限制。原始 HTML/Markdown 是不可信内容，页面仅按文本展示。
- 原始文件上传后不覆盖；重新计算 SHA，结果写入发生冲突时拒绝覆盖。
- 当前无自动清理历史数据；需制定存储配额、备份和人工保留策略后再扩大使用规模。
- 数据库保存了解析结果和来源，不代表法律效力确认。普通材料可以审阅，但泛文档 Chunking/表格入知识库 GAP-008 仍待确认。
- 页面刷新后应保留任务 ID；当前页面内重试保留请求键，不声称跨设备会话恢复。
- 真实官网验证仅覆盖合成单页；真实资料识别准确率、复杂表格和大批量性能待 QA 验收。
