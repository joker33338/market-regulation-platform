批次标识 `law-import-20261113`。每份可接收原件复制到既有状态存储中独立 owner 目录，使用真实 source_file_id；121 个文件均独立核对原件 SHA-256 及既有 FrontendReader.upload 的受控解析路径。验证是本机存储解析，不是正式 HTTP 登录或浏览器验收。

PostgresResultSink.save_import 复用已有解析结果事务写入，保留页面、块和表格。来源记录 import_batch_id，不填写虚构的 local_task_id；没有伪造 SQLite 队列任务，也没有修改 SQLite 解析任务存储。接收作业标记 authorized_local_job，不产生任何 MySQL 人工审核事件。

117 条目录复用 public.mr_document_versions，但 metadata 明确 processing_status=INTAKE_NOT_INDEXED、publication_eligible=false、human_verified=false，chunk_count=0。未将这些版本加入 mr_kb_documents，也没有建立 KB 发布版本。业务 doc_id 暂为稳定源内容身份，不自动合并同名法规或推断修订沿革；后续需要人工确认法律身份。

目录 title 仅使用真实原文件名作为未核验显示标题，facts_source/title_basis 均明确为 original_filename_unverified，不冒充已核验的完整法规名称。法规编号、发布日期、实施/废止日期、发布机关、类别、效力状态均未猜测填写。需要核验后通过明确流程补齐。

所有 PDF 页面的文本层先只读核对。本批次最终接收使用现有 pdf_page/native_docx 组件保留原生文字、页面和表格，未重写 OCR/RAG。本机 PP-Structure 增强曾因复杂版面耗时过长中止，未用未完成增强声明完整识别；最终文字层候选及版面异常明确留待核验，没有云端 OCR 调用或模型下载安装。
