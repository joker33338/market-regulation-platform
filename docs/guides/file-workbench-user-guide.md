# 文件从上传到入库：操作说明

本说明对应开发分支的新版文件工作台；正式8180尚未切换本轮功能。界面无需查内部ID、填写JSON或手动填写版本锁。

## 添加文件

1. 打开「文件处理工作台」，选择多个文件或一个文件夹。子文件夹保留分组名称。
2. 核对批次名称；整批都是法规或处罚案例时可直接确认整批类别，混合资料选择稍后逐份确认。
3. 点击「上传并开始处理」。重复内容、不支持格式和失败项分别显示。上传时保持页面打开；已提交的后台任务可离开页面后继续处理。
4. 在「处理中」查看解析阶段；失败文件进入「需处理」。只重试失败项，不需要重新提交成功文件。

## 查找与连续查看

- 搜索文件名、资料标题、文号或案号，并组合类别、批次、上传时间和处理阶段。
- 修改条件后点击查询；清空筛选返回全部范围。常用条件可以保存在当前账号的本机浏览器。
- 点击名称打开原件；上一份/下一份可以跨列表页连续查看。回到列表保留查询和页码，审核返回保留原查询。
- 翻页后选择仍保留。「选择全部筛选结果」会固定当时的完整范围，有效期1小时。改变筛选会先确认清空选择，不会把后来新出现的文件混入此次操作。

## 确认资料信息

在文件中点击「确认归类并准备入库」，核对资料名称和目标库。标题与分类建议需要人工确认。

汇编有多篇资料时选择「按篇分别入库」，逐篇核对标题和正文范围。可选中正文设定整篇范围；内容跨正文段时，分别设置起点和终点。范围必须包含该篇完整正文。目录、引文和重复标题可能使建议不准确，无法可靠确定时先保留为待处理。

每篇独立生成资料，仍关联同一原文件；多篇文件部分发布不会显示为整份发布。

## 人工审核与修订

打开「查看与审核正文」，对照原文件与识别正文，异常资料优先处理。可审核通过、退回、标错或保存人工修订。

整页修订必须填写该页完整正文；保存的是审核副本，原始OCR和原文件保留。保存后查看「当前审核正文」，核对后再次审核通过。历史修订含义不明确时需重新确认，系统不会猜测它是整页还是局部文本。

批量审核必须先选择范围，再勾选已核对声明并确认操作。后台逐份记录成功和失败；某份来源或版本变化会单独失败。批量审核不是自动替用户判断内容正确。

## 准备与发布

确认资料并审核通过后，系统自动使用已有解析结果准备候选，不重新走OCR/MinerU。普通用户不能自动取得管理员权限；需要管理员接手的记录会明确显示。

1. 打开「入库与发布」，查看每条资料的真实处理步骤。
2. 管理员选择准备好的资料，或点击「准备全部待发布资料」。
3. 核对清单中每一条资料的名称、目标库及总数，点击「确认发布这份清单」。未准备好、未审核或后来新增的资料不会自动混入此次发布。
4. 成功后点击「查看发布结果」，在法规库或处罚案例库查阅。本次候选未发布时，正式库不会出现它。

审核通过、解析完成和发布成功是不同阶段。提示版本冲突或服务不可用时，不要把页面未报错当作成功；查看实际处理记录后重试。表格或正文不完整的资料须先解决问题，系统不会省略异常内容后强行发布。
