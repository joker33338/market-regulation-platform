## 本轮标准与版本身份

采用用户最新确认的“功能安全门禁 + 识别质量分级 + 人工复核”。核心功能、完整性、追溯、权限、预算、幂等和安全要求不降低；OCR 试行参考为文字版 1%～3%、普通扫描 ≤5%、复杂扫描 ≤10%，不把单个困难样本超限作为一票否决。表格文本和结构分别统计，90% 为试行参考；关键结构错误仍须复核。路由不再机械要求 95% 意图匹配。标准答案、样本和既有功能断言不变。

“识别不合格”“复核信号正确”“审核门禁阻断有效”是三项独立结论；仅有 requires_review=true 不足以证明未经审核入库已被阻断。document_review 解析结果存储也不等于进入检索知识库或发布 ACTIVE。
